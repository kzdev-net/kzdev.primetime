# Contributing

## Pull requests

**External pull requests are not accepted.** Unsolicited PRs will not be reviewed or merged.

This policy keeps maintenance scope manageable for the maintainers of this repository.

## How to contribute feedback

You can still help improve the project:

- **Bug reports:** GitHub [Issues](https://github.com/kzdev-net/kzdev.primetime/issues).
- **Questions and usage discussion:** GitHub [Discussions](https://github.com/kzdev-net/kzdev.primetime/discussions).
- **Small feature ideas:** Issues are appropriate; inclusion in the product is not guaranteed.

See [SUPPORT.md](SUPPORT.md) for support expectations, versioning, and lifecycle context.

## Security

Report vulnerabilities according to [SECURITY.md](SECURITY.md).

## Copyright and licensing

Hand-authored source files under `Source/Src/` must begin with this two-line header (no year in per-file headers; the year appears in [LICENSE](LICENSE) only):

```text
// Copyright (c) Kevin Zehrer
// Licensed under the MIT License. See LICENSE file in the project root for full license information.
```

The header must be the first lines of the file, before any `using`, `#if`, or `namespace` directives.

The project is licensed under the [MIT License](LICENSE). Full license terms are in that file at the repository root.

Auto-generated files (for example `*.Designer.cs` from resource generators) are exempt from the per-file header; do not edit them manually to add copyright lines.
