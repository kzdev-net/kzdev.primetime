# Contributing

## Pull requests

**External pull requests are not accepted.** Unsolicited PRs will not be reviewed or merged.

This policy keeps maintenance scope manageable for the maintainers of this repository.

## How to contribute feedback

You can still help improve the project:

- **Bug reports:** GitHub [Issues](https://github.com/kzdev-net/kzdev.primetime/issues).
- **Questions and usage discussion:** GitHub [Discussions](https://github.com/kzdev-net/kzdev.primetime/discussions).
- **Small feature ideas:** Issues are appropriate; inclusion in the product is not guaranteed.

See [SUPPORT.md](SUPPORT.md) for support expectations, versioning, and lifecycle context.

## Security

Report vulnerabilities according to [SECURITY.md](SECURITY.md).
